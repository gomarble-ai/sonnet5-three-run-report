Costs cover the selected executions behind the 8-September GoMarble results. Estimated USD costs include recorded model tokens and exclude grading, infrastructure, superseded attempts and unrecorded provider charges. These are usage-based estimates, not AWS invoice totals.

Verified in saved records and the local evaluation database: all 90 selected executions match, covering 102 assistant usage summaries and 783 provider-call token records. Database access was read-only.

Why Terra is a range: its cache-write token counts were not saved in either source. The lower estimate prices all non-cache-read input as ordinary input; the upper estimate prices it all as cache writes. Every request was below the 272K pricing threshold. Reasoning tokens are already included in output. Its unpriced cost fields do not mean execution was free.

Bedrock currently has no configured invocation-log destination in us-east-2. This check does not establish whether historical logs exist.

Sonnet includes cache reads plus five-minute and one-hour cache writes. Its 418 per-call costs reconcile with the saved totals.
